# 福緣顧客訂購

入口：<https://evil-deny.github.io/customer/>。

商品、顧客價、可售庫存與是否顯示，由共用 backstage 後台管理。此頁每 20 秒讀取最新目錄，切回頁面及按「更新商品」也會更新。過季品項隱藏後不再出現在目錄；送單時伺服器再次確認價格、供貨與庫存。

顧客無須登入 ChatGPT。按「送出訂單並保存明細」後，訂單寫入共用資料庫，管理員可在 backstage 後台查看、出貨與退貨。LINE 與複製明細功能保留。

價格為 0 表示時價；實際供貨與取貨方式仍由店家確認。連線失敗會顯示錯誤，不會把僅儲存在瀏覽器的資料誤當成已送達訂單。相同訂單重送不會重複扣庫存；已送達的訂單如要改內容，應開始另一張訂購單並聯絡店家取消舊單。

原有瀏覽器的購物車與「我的明細」仍保留；舊版僅存於瀏覽器的明細不會自動搬到雲端。

`assets/cloud-sync.js` 為跨站連線程式，公開 API 網址可見但不含管理密碼或私密金鑰。網站從 `main` 分支根目錄發布到 GitHub Pages。

明細顯示簡短單號，完整 ID 仍保留於本機與雲端資料。送單成功會通知同一瀏覽器的員工分頁更新；訂單進入共用待出貨清單。


商品支援獨立的批發單位（`orderUnit`）與顧客單位（`customerUnit`），舊商品預設為「件」。公開商品依入口只回傳該入口的 `price` 與 `unit`。新訂單保存價格與單位快照，出貨與退貨沿用原單位；分析依商品與單位分列。單位是販售標示，共用庫存仍按數量扣除，不會自動換算箱／包。後台點擊商品縮圖可放大，支援關閉按鈕與 Esc。

新增商品使用伺服器分配的連續固定編號（p198、p199…），隱藏商品仍保留編號，既有商品與歷史單據不改號。目錄共用 catalog-order.js，依原本分類、冷凍／冷藏／乾貨、既有類別順序、中文商品名稱（含數字自然排序）排列；新增或修改分類後自動排入，新增類別排在既有類別之後。

原本分類沿用原目錄順序：公司庫存 → 兩天一次(三五日結單/一四六到貨)；新分類接在既有分類之後，依中文名稱排序。訂購畫面按原本分類、保存方式及類別分組，避免跨分類混排。
